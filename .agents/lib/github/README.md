# GitHub Shared Procedures

Reusable procedures for GitHub issue and PR workflows in the superproject.

## Available Procedures

| Procedure | Description |
| --------- | ----------- |
| `setup.md` | Authenticate and detect canonical repo, base branch, and remotes |
| `lookup-pr.md` | Find a PR by number or head branch |
| `branch-naming.md` | Generate a branch name from the intended change |
| `commit-and-push.md` | Rebase, squash if needed, and push safely |
| `detect-permission.md` | Determine whether the current user can push to a PR |
| `checkout-fork-branch.md` | Create or refresh a local work branch for a fork PR |
| `fetch-comments.md` | Fetch unresolved review threads |
| `reply-and-resolve.md` | Reply to a review comment and resolve its thread |
| `common-issues.md` | GitHub CLI troubleshooting notes |
